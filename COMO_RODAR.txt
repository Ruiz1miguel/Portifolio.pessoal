PORTFOLIO - PAGINAS HTML E PHP SEPARADOS (DWS)

1. Inicie Apache e MySQL no XAMPP.
2. Importe banco.sql pelo phpMyAdmin.
3. Copie a pasta Portifolio_Pessoal_2 para htdocs.
4. Abra http://localhost/Portifolio_Pessoal_2/index.html

As paginas do site ficam em index.html e pages/*.html.
JavaScript usa fetch para consultar php/api.php, que retorna JSON do MySQL.
O formulario envia POST para php/create.php.
O painel CRUD administrativo continua em php/read.php, dentro da pasta php/.
O banco.sql permanece sem alteracoes.

ATENCAO: rode pelo localhost, nunca abrindo o HTML com file://.
O painel nao possui autenticacao e as mensagens sao exibidas publicamente.
Nao publique este projeto na internet sem rever privacidade e seguranca.
